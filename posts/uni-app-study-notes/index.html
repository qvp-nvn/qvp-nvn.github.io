uni-app 学习笔记

发表于2024-11-03|更新于2026-10-06|前端开发

uni-app 的定位是「一套代码，多端发行」——用 Vue 语法写一次，编译到微信小程序、支付宝小程序、H5、Android / iOS App 等十几个平台。这篇记录从环境搭建到多端发布的主线，以及踩过的坑。

一、它凭什么能跨端

uni-app 在 Vue 之上做了两件事：

  1. 统一组件与 API：把各端原生的组件和接口抽象成一套 <view>、<text>、uni.request() 这样的通用写法，编译时再翻译到目标平台
  2. 条件编译：遇到平台差异（比如只有微信小程序有开放能力），用注释标记让某些代码只在指定平台生效

所以它不是「写一次完全不用管差异」，而是「大部分代码共用，差异处单独处理」。

可以直接对标理解：

Web 写法 uni-app 写法 说明
<div> <view> 块级容器
<span> <text> 文字，只有它才能长按选中
<img> <image> 图片，默认有尺寸，需写 mode
<a> / 路由跳转 uni.navigateTo() 页面跳转
axios / fetch uni.request() 网络请求
localStorage uni.setStorageSync() 本地缓存

二、开发环境

两种方式，选一个即可：

官方 IDE，开箱即用、内置真机运行与云打包，适合新手和 App 开发。

  1. 下载安装 HBuilderX（选 App 开发版）
  2. 文件 → 新建 → 项目 → 选择 uni-app → 选默认模板
  3. 运行 → 运行到浏览器 / 小程序模拟器 / 手机

适合熟悉 Vue 生态、想用 VS Code + 自定义构建流程的开发者。

微信小程序端还需：把 dist/dev/mp-weixin 用微信开发者工具打开，并在工具里开启「服务端口」。

分三层，别记混：

五、样式与单位 rpx

uni-app 用 rpx（responsive pixel）做自适应：设计稿按 750rpx = 屏幕宽度 出图。

750 这个基准来自 iPhone 6（375pt × 2）。设计稿如果是 750px 宽，标注多少 px 就写多少 rpx，不用换算，这是最舒服的地方。

样式注意点：

  • 页面样式写在 <style> 里默认只对当前页面生效（已自动加 scope）
  • 想写全局样式放 App.vue
  • 单位别混用，项目里统一 rpx
  • 小程序端不支持 * 选择器、不支持部分 CSS3 高级选择器

七、路由与页面跳转

五个 API，区别在于是否保留当前页和能否跳 tabBar：

API 行为 能否跳 tabBar 页面栈
uni.navigateTo 保留当前页，打开新页 ❌ 入栈
uni.redirectTo 关闭当前页，打开新页 ❌ 替换
uni.switchTab 切换 tabBar 页 ✅ 清空非 tab 页
uni.reLaunch 关闭所有页，打开新页 ✅ 清空
uni.navigateBack 返回上一页 — 出栈

navigateTo 最多只能再开 9 层页面栈，层级深了会失败。表单流程这类场景改用 redirectTo。

九、数据缓存

小程序端单个 key 上限 1MB、总容量约 10MB，别往里塞大对象。图片路径、长列表这类数据不要缓存，token 和用户信息这类小数据可以。

十、组件库推荐

库 特点 适用
uni-ui 官方出品，按需引入，跨端一致 求稳、官方项目
uView Plus 组件丰富、文档友好（Vue3 版） 业务系统、后台类
uv-ui uView 的 Vue3 兼容分支 老项目迁移

按需引入（uni_modules 方式）直接在插件市场导入即可，不用手动配置。

十一、打包发布

目标端 操作
微信小程序 npm run build:mp-weixin → 微信开发者工具打开 dist/build/mp-weixin → 上传 → 后台提交审核
H5 npm run build:h5 → 把 dist/build/h5 传到服务器/CDN（注意路由 history 模式需配置重定向）
App HBuilderX → 发行 → 云打包（无需 Mac 也能出 iOS 包）

发行前检查清单：

  • manifest.json 里填好各端 AppID
  • 关闭 debug、移除 console
  • 接口域名已加入小程序后台的服务器域名白名单（必须是 https）
  • 隐私协议已配置（现在审核必查）

十二、常见坑速查

现象 原因 解法
页面白屏 / 找不到 没在 pages.json 注册 补上路由配置
跳转 tabBar 页失败 用了 navigateTo 改用 switchTab
网络请求失败 域名未在小程序后台配置 加白名单，开发时可勾选「不校验合法域名」
图片不显示 static 路径写错，或用了本地绝对路径 用 /static/xxx.png，网络图要配白名单
样式不生效 用了一端不支持的选择器 避免 * 选择器、简化选择器
真机正常但模拟器报错 部分 API 模拟器不支持 以真机为准
scroll-view 无法滚动 没设固定高度 给它设明确 height（如 100vh 减去头部）

一句话总结：uni-app 的核心成本不在语法（就是 Vue），而在各端差异处理。把条件编译和平台 API 差异摸清，剩下的就是普通 Vue 开发。
