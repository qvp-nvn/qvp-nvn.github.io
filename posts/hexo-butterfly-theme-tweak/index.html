Butterfly 主题更改

发表于2024-01-09|更新于2026-10-06|博客搭建
|阅读量:

Butterfly 是 Hexo 里配置最细致的主题之一，好处是几乎什么都能改，代价是配置文件长得让人迷路。这篇把常用改动按「改哪里 → 改什么 → 效果」的方式记下来，配的正是本站（Butterfly 4.x）。

一、先分清两个配置文件

新手最容易改错文件，先记住这张表：

文件 管什么 什么时候动
_config.yml 站点：标题、作者、URL、部署、插件 换域名、改部署、装插件时
_config.butterfly.yml 主题外观：导航、配色、侧边栏、评论 改样式、加功能时

主题配置要放在 _config.butterfly.yml（根目录），不要直接改 themes/butterfly/_config.yml —— 主题一升级就会被覆盖，改动全丢。

CSS 覆盖不生效时的排查顺序：

  1. 文件是否真的被引用（看页面源码里有没有这个 <link>）
  2. 加载顺序 —— 自定义 CSS 必须在主题 CSS 之后
  3. 选择器特异性不够 —— 去 public/css/index.css 里搜原规则，看它用了几层选择器，照着补齐（比如主题写 #nav .site-page:not(.child):after，你只写 #nav .site-page::after 就压不过它）
  4. 浏览器缓存 —— 强制刷新 Cmd + Shift + R

十二、值得装的插件

插件 作用
hexo-abbrlink 生成短链接（/posts/xxxx.html），比中文路径友好
hexo-wordcount 字数与阅读时长统计
hexo-generator-sitemap / hexo-generator-baidu-sitemap 生成 sitemap，提交搜索引擎用
hexo-bilibili-bangumi 追番页面
hexo-butterfly-swiper 首页轮播图（本站用了 swiper_index）
hexo-filter-nofollow 外链加 nofollow，有利于 SEO

十三、常见坑

现象 原因 解法
改了配置没生效 没执行 hexo clean 清缓存后重新生成
菜单点进去 404 没创建对应 page hexo new page xxx
样式改了不生效 选择器特异性不够 / 缓存 见第十节排查顺序
部署后文章链接变了 permalink 或 abbrlink 配置变了 改链接后必须配 301 重定向
图片不显示 路径大小写、中文文件名 用相对路径 /img/x.png，避免中文名
搜索无结果 本地搜索索引未生成 确认装了 hexo-generator-search

改动原则：能用配置解决的不写代码，能靠 CSS 覆盖的不改主题源文件。这样主题升级时一条 git pull 就能跟上，自己的定制也不会丢。
