板绘学习

美术人体动态结构课程笔记

一、课程说明

1. 教师自我介绍

  • 专业背景: 美术游戏原画工作13年经验，涉及场景、角色设计和电影海报
  • 项目经验: 参与过《上古卷轴》《魂斗罗》《真龙霸业》《捕鱼达人》等项目
  • 教学专长: 现专注于人体动态结构类教学

2. 班级学生基础情况

  • 学员构成: 57%零基础学员，部分有美术经验和工作经验
  • 学习建议:
    • 零基础学员避免盲目攀比
    • 有基础学员不应轻视基础课程
    • 所有学员都应踏实打好基础

3. 上课时间安排

  • 正课时间: 每周六下午3-5点，晚上8-10点
  • 辅导课:
    • 周二晚：解决作业难题
    • 周五晚：作业问题总结与专项练习

4. 课程周期与作业安排

  • 课程周期: 12周(6月24日-9月8日)
  • 作业截止: 9月15日
  • 加课安排: 优秀学员会有额外课程

5. 课程录播保存政策

  • 默认保存: 1年
  • 延长条件: 全班作业完成情况良好可延长至2年

二、软件介绍

  • 教学软件: Photoshop CS6
  • 可选软件: Procreate或其他PS版本
  • 学习资源:
    • 小鹅通基础教程
    • B站教程(半天可掌握基础)

三、找参考

1. 找参考误区

  • 错误观念:
    • 认为学画是为了不找参考
    • 认为原创作品不能有参考
    • 使用过度修图的图片作为参考
    • 参考与创作内容关联性低
  • 正确方法:
    • 参考应有清晰结构
    • 借鉴而非照搬
    • 参考应与创作目标相关

2. 怎么找参考

  • 专业网站:
    • A站: 全球专业艺术家平台
    • P站: 智能图片推荐
    • 花瓣: 画板收集功能
    • Sketchfab: 3D模型参考
    • Pofi无限人偶: 动态参考
  • 参考技巧:
    • 学习一流作品提升审美
    • 建立个人素材库
    • 使用3D模型多角度观察
    • 参考应服务于创作目标
  • 案例解析:
    • 借鉴动态而非照抄
    • 分部位寻找参考(头部、服装等)
    • 组合多个参考创作新作品
  • 审美培养:
    • 避免学习三流作品
    • 每日浏览专业作品”洗眼”
    • 审美决定进步上限

    • 专业画家的大量作品也不参与课程批改

六、正课

1. 人体动态与透视的建立

1）第一节课课程总结

  • 核心要素：人体绘画需要掌握三个关键要素：比例、空间关系和体积意识。
  • 练习顺序：第一步要熟悉人体比例，第二步培养空间意识，第三步理解体积与空间的区别。
  • 工具使用：课程中演示了套索工具、笔工具等Photoshop工具的使用方法。

人体绘画步骤分解

  1. 步骤1-比例：确保人体各部分比例准确，这是绘画的基础。
  2. 步骤2-平衡：注意画面的平衡感，避免人物显得僵硬。
  3. 步骤3-剖面：理解人体各部位的剖面结构。
  4. 步骤4-透视：掌握不同角度下的透视关系。
  5. 步骤5-圆柱体：用圆柱体构建人体基本形态。
  6. 步骤6-方块转换：将圆柱体转换为方块，确定正侧面关系。
  7. 步骤7-透视强化：运用1点、2点、3点透视增强立体感。
  8. 步骤8-动态表现：通过方块扭转表现动态感。

新手常见问题

  • 心理障碍：新手往往不敢下笔，容易被照片细节带偏。
  • 框架缺失：缺乏系统的绘画流程和框架。
  • 比例失调：常见问题包括手部过长、腰胯分离等。
  • 细节过度：过早关注衣褶等细节而忽略整体比例。

高手绘画方法

  • 问题分解：将复杂问题拆解为多个简单小问题。
  • 小稿准备：即使是经验丰富的画师也会先做比例小稿。
  • 流程优化：建立明确的绘画步骤，从火柴人开始逐步完善。
  • 极致细节：对每个简单问题都做到极致处理。

2）新手画画时容易存在的问题

  • 比例错误：常见如手部过长、四肢连接不当等问题。
  • 结构分离：腰胯分离、衣服与身体脱节等现象。
  • 细节迷失：过度关注衣褶等细节而忽略整体造型。
  • 步骤混乱：直接进入细节刻画而跳过基础构建阶段。

问题案例分析

  • 案例1：手部比例严重失调，长度超出正常范围。
  • 案例2：衣服表现与身体结构脱节，显得”穿哥哥的小衣服”。
  • 案例3：腰胯部位结构分离，缺乏整体连贯性。
  • 案例4：腿部比例异常，大腿与小腿关系失衡。

正确绘画方法示范

  • 小稿先行：即使是专业画师也会先绘制比例小稿。
  • 步骤明确：从火柴人开始，逐步构建形体。
  • 光影处理：专业画师的光影表现干脆利落。
  • 基础扎实：所有优秀作品都建立在准确的比例基础上。

3）人体基本比例

示例图解析

  • 二分法核心：将人体比例简化为两个关键的一比一关系
    • 第一组：胯部底端为分界点，上半身（胯部到头顶）与下半身（胯部到脚掌）长度相等
    • 第二组：大腿长度与小腿长度完全相等
  • 三分法要点：上半身分为三个等长部分
    • 第一段：头颈联合部分（含头部和颈部）
    • 第二段：完整胸腔长度
    • 第三段：腰椎联合骨盆区域
  • 手臂定位技巧：
    • 上臂长度参照骨盆纵向长度
    • 前臂与上臂保持一比一关系
    • 手臂自然下垂时，指尖位置与骨盆底部平齐
  • 动态捕捉方法：
    • 先用三个球体表示头颈、胸腔、骨盆三大体块
    • 注意体块间角度变化（如典型站姿中头颈与胸腔约130°夹角，胸腔与骨盆约100°夹角）
    • 通过体块倾斜角度表现人物动态感
  • 比例验证技巧：
    • 手臂摆动时保持”自行车轮辐原理”：肩关节到指尖的虚拟连线应与躯干中线形成对称角度
    • 腿部比例快速检查法：大腿长度应等于小腿长度（含脚掌厚度）
  • 简化绘制流程：
    • 用三个圆形定位头颈、胸腔、骨盆
    • 注意头颈圆最小，胸腔圆最大（需包含颈部长度）
    • 骨盆圆需包含腰椎部分
    • 按一比一关系延伸四肢线条
  • 常见误区提醒：
    • 避免将躯干画成直线排列的体块（会导致僵硬感）
    • 注意骨盆区域实际包含腰椎部分（约占1/3长度）
    • 手臂长度测量应以骨盆为基准而非胸腔

4）动态趋势

火柴人基础构建

  • 角度确立：先确定火柴人的动态站姿和整体角度，这是后续绘制的基础框架
  • 比例关系：手臂长度与胸腔底部面需保持一致，上臂与前臂的标准比例为1:1
  • 透视表现：当手臂剖面面向观众时会显得更短，这与剖面角度和透视程度相关

比例练习方法

  • 三圈定位法：用三个圆圈（头、胸腔、骨盆）先确定基本比例关系，保持1:1:1的基础比例
  • 动态修正：即使比例正确，若动态失衡仍会显得奇怪，需通过”Z字型”转折来增强稳定性
  • 平衡原理：参考伯里曼人体理论，稳定动态应像叠酒瓶一样形成前后交替的支撑结构

5）画简单结构

身体区块划分

  • 三大组件：头部（可缩小）、胸腔（可调整角度）、骨盆（需注意倾斜关系）
  • 连接关系：通过腰椎连接胸腔和骨盆，形成可调节的动态曲线
  • 观察技巧：眯眼观察整体轮廓的曲折关系，培养对角度变化的敏感度

腿部绘制技巧

  • S型曲线：大腿前1/3处凸起→膝盖后收→小腿后1/3处再凸起→脚踝前收
  • 比例调整：大腿略短于小腿（视觉上更美观），小腿越长人物显得越高挑
  • 错位原理：膝盖位置应使大腿和小腿形成前后错开的关系，而非直线排列

6）画面平衡

锁足点原理

  • 重心判定：从锁骨中心点（颈窝）垂直向下到主要受力的脚部位置
  • 双足站立：当两腿均受力时，重心线在两脚之间；单腿受力时则在受力腿正上方
  • 平衡验证：若锁足点偏离受力区域（如抬腿时重心仍在两脚间），动态就会失衡

钟摆动态理论

  • 力学原理：人体动态类似钟摆运动，动作幅度越大，反向平衡力也需要越强
  • 应用示例：当胸腔前倾时，骨盆和腿部必须产生反向力矩（如后伸腿部）来维持平衡
  • 夸张处理：在保证锁足点正确的前提下，可适当夸张动态增强画面张力

综合绘制步骤

  1. 定比例：用几何体概括主要身体部件
  2. 抓动态：建立”S”型或”Z”型韵律线
  3. 调平衡：通过锁足点验证重心稳定性
  4. 做夸张：在合理范围内强化动态表现

7）应用案例

例题:人物动态平衡问题

  • 框选定位法：
    • 将人物最高点和最左右点用方框框住，中心线即为画面平衡点
    • 适用于平视状态下的人物动态分析，如站立、行走等基础动作
  • 锁足点原理：
    • 当人物双脚着地时，锁骨与足部的连线应通过重心
    • 示例中角色因脚尖踮起几乎不受力，故锁足点判断非常准确
  • 配饰调节技巧：
    • 当角色动态失衡时，可通过添加头发、背包等配饰来平衡画面
    • 如案例中长发飘向画面左侧，有效补偿了右侧的视觉重量

例题:人物动态平衡问题

  • 透视空间构建法：
    • 通过脚部与地面的接触点确定底部透视面，再向上延伸建立立体方框
    • 适用于俯视/仰视等非平视状态，如案例中的高跟鞋角色
  • 十字定位技巧：
    • 在透视方框内打十字交叉线，中心交点即为动态平衡点
    • 类似”穿珠子”训练，通过空间线串连找到精确重心位置
  • 常见错误：
    • 忽略脚部透视关系会导致整体动态失衡
    • 示例中角色因未考虑近大远小规律，造成重心偏移

例题:人物动态稳定性问题

  • 稳定性判定标准：
    • 优秀动态应同时满足：视觉动感强、韵律感好、物理平衡合理
    • 案例3因中心点精准落在两腿之间而成为最佳范例
  • 修正方案：
    • 调整脚部位置：将支撑脚移至方框中心线下方
    • 添加平衡元素：用飘带/武器等道具补偿视觉重量
  • 典型错误：
    • 案例1因头饰位置不当导致重心偏移
    • 案例2脚部透视错误造成”即将倾倒”的视觉效果

例题:人物动态稳定性问题

  • 三要素构建法：
    • 比例控制：保持头身比协调（如7-8头身）
    • 重心平衡：确保支撑点位于中心线下方
    • 透视校正：遵循近大远小原则调整肢体粗细
  • 脚部绘制技巧：
    • 用两个三角形组合表示脚部结构
    • 前三角对应脚掌，后三角对应脚跟
  • 动态发散训练：
    • 先固定头部位置，用方框法确定腿部落点
    • 在保证重心的前提下自由设计肢体动作

例题:人物动态稳定性问题

  • 俯视处理要点：
    • 按透视规律缩短下肢比例（近大远小）
    • 示例中大腿长度需调整为头部的1.5倍左右
  • 动态线辅助：
    • 用”S”型曲线串联头、胸、骨盆三大体块
    • 看似倾斜的姿势实际重心仍保持在支撑面内
  • 常见误区：
    • 过度追求造型夸张而忽视物理合理性
    • 案例显示脚部位置偏差1cm即导致明显失衡感

2. 动态平衡与中心点调整

1）中心点确定方法

  • 手部动态影响：当手部动态变化较大时（如伸展过长），需要重新确定中心点位置，通常需要向左偏移以保持平衡
  • 多因素综合考量：中心点调整需同时考虑头发、披风等附加物体的动态变化，不能仅看单一部位
  • 方块检测法：用虚拟框包围整个人物，取框的几何中心作为平衡点，比单纯用锁骨点更准确可靠

2）人体比例关系

  • 臂长基准：前臂长度(小b)与上臂长度(大b)相等，两者保持1:1比例关系
  • 腿身比例：舞蹈角色设计中常采用”上身短腿长”的夸张比例，通过拉长腿部自然缩短上身视觉效果
  • 关键转折点：大腿1/3处和小腿1/3处是动态曲线的重要转折点，标记这些点有助于塑造自然姿态

3）动态平衡检查

  • 中心线作用：主要用于动态检查而非设计辅助，确保角色在画面中能”站稳”
  • 透视处理：当透视较强时，必须使用方块检测法来验证空间中的平衡关系
  • 运动状态例外：如盲僧踢腿等明显运动中的姿势，可不考虑静态平衡问题

3. 剖面表现技法

1）剖面核心概念

  • 体积表现关键：剖面比轮廓更能准确表达物体的空间体积和透视角度
  • 完整闭环原则：剖面线应形成完整环形（包括不可见部分），不能像”瓜子壳”一样突然中断
  • 角度转换：通过改变剖面弧度，可使同一轮廓呈现仰视/俯视等完全不同的空间效果

2）剖面绘制要点

  • 转折处理：肢体转折处必须明确表现剖面转折，避免出现生硬的直角过渡
  • 多剖面组合：完整人体需要在大腿、小腿、胸腔等多个关键部位绘制剖面
  • 虚实结合：可见部分用实线，不可见部分用虚线，共同构成完整的体积信息

3）常见错误

  • 平面化问题：仅关注轮廓准确而忽略剖面，会导致角色缺乏立体感
  • 剖面不完整：只画可见部分剖面线，使物体像被”切开”的扁平状态
  • 弧度不合理：剖面弧度与整体透视不符，造成空间关系混乱

4. 标准人体比例构建

1）基础比例框架

  • 三大段划分：头部空间、胸腔长度、腰椎长度构成基本比例框架
  • 肩胯对应：正常情况下肩膀宽度与骨盆宽度基本一致（特殊体型除外）
  • 腿长优化：艺术处理时通常加长小腿比例（大腿:小腿≈1:1.2）使视觉效果更佳

2）空间定位方法

  • 十字定位法：在虚拟方块中打十字交叉线确定中心点位置
  • 渐进构建：先确定头部空间，再依次构建脖子、胸腔、腰椎等部位
  • 比例验证：手臂自然下垂时，指尖位置应在大腿中段附近

3）侧面表现要点

  • 曲线转折：侧面视角需重点表现脊柱的S形曲线转折
  • 厚度表现：通过剖面线明确胸腔厚度、骨盆倾斜度等空间信息
  • 动态预览：在方块中预先确定动态线走向，再细化各部位比例

七、动态趋势

  • S型曲线构成：从头部到脚部形成连续S型曲线，具体表现为：头部低头→胸腔挺起→骨盆回收→大腿前倾→膝盖后移→小腿前收
  • 关键节点比例：所有转折点均按1/3比例划分，如大腿分前1/3和后2/3，小腿同样遵循此比例
  • 中心点定位：头部位于中心点前侧，胸腔抬升时中心点需前移，骨盆回收时重新回到原始中心位置

1. 躯干动态

  • 头部定位：头部应低于中心线，颈部连接点位于中心点前侧约1/3处
  • 胸腔处理：需明显挺起，与头部形成反向角度，中心点需前移约15度
  • 骨盆调整：在胸腔挺起后自然下收，与胸腔形成第二个反向转折点

2. 腿部动态

  • 大腿分段：先将大腿分为两等份，再在前段取1/3处作为转折点
  • 空间关系：大腿前1/3→膝盖后1/3→小腿后1/3→脚部回正，形成连续空间转折
  • 裆部注意：需区分裆部线与腿部起始线，大腿实际起始点高于裆部线约1/6比例

八、趋势分析

  • 双S结构：上半身（头-胸-盆）与下半身（大腿-膝-小腿）各自形成独立S型，最终组合成完整动态
  • 骨盆基准：以骨盆为中间分界点，上下动态最终都需回归骨盆中心线
  • 角度修正：
    • 四分之三侧视时，正对观众的腿部转折角度需减小30%
    • 脚部自然呈外八字，单脚倾斜角度建议15-20度
  • 透视处理：当肢体正对观众时，转折面会变薄，转折幅度应减少50%以符合透视原理

九、圆柱体和火柴人的套嵌关系

1. 套嵌关系分析

  • 平行原则: 圆柱体外轮廓线必须与火柴人结构线保持平行，否则会导致套嵌失效。例如画圈时若两侧线条不平行，火柴人的结构表现就会失真。
  • 中心定位: 圆柱体剖面中心点必须与火柴人关节点重合，绿色标记点应准确位于圆柱体中心位置。
  • 比例控制: 头部圆柱体应较小，胸腔圆柱体长度略短于骨盆，需预留腰椎空间。

2. 剖面平行

  • 相对平行性: 同一圆柱体的上下剖面必须保持相对平行，若上剖面为角度A，下剖面不能突然变为B。
  • 趋势线应用: 在肢体三分之一处绘制剖面时，需遵循趋势线的走向规律，如腿部剖面应位于骨盆下方特定位置。
  • 空间包裹: 圆柱体需完整包裹火柴人线条，通过练习使圆柱体在不同角度都能准确贴合结构线。

3. 透视与剖面弧度

  • 弧度定律: 剖面弧度与肢体长度成反比关系，具体表现为：
    • 正圆形剖面（最大弧度）对应最短肢体
    • 扁平剖面（最小弧度）对应最长肢体
    • 中间状态按比例变化
  • 透视调整: 当肢体转向观众时：
    • 正面视角：剖面弧度最大，视觉长度最短
    • 侧面视角：剖面趋平，视觉长度增加
    • 可通过0°/45°/90°等具体角度演示变化过程
  • 关节处理: 将关节视为球形枢纽，其剖面弧度决定连接肢体的表现长度，需保持：
    • 上臂与前臂的剖面协调
    • 大腿与小腿的弧度渐变
    • 避免出现剖面弧度突变造成的比例失调

十、比例和穿插

1. 俯视和仰视

1）透视叠压关系示例

  • 透视变形原理：通过改变裆部在画面中的比例实现透视变化，俯视时裆部比例缩短，仰视时裆部比例拉长
  • 近大远小规律：
    • 俯视时：头部最大 → 胸腔次之 → 骨盆最小
    • 仰视时：骨盆最大 → 胸腔次之 → 头部最小
  • 常见误区：仅调整比例不处理叠压关系会导致透视感缺失，画面仍显平面化

2）俯视透视关系分析

  • 叠压关系三要素：
    • 角度越大叠压越明显（俯视角度与叠压面积成正比）
    • 焦距变化影响叠压程度（33mm焦距为标准参考）
    • 球体间距离随角度增大而缩短（最终完全重叠）
  • 强化技巧：
    • 头部与胸腔：部分重叠
    • 胸腔与骨盆：增加遮挡面积
    • 腿部处理：近端粗远端细，脚部平面化
  • 动态调整：
    • 俯视时上半身拉长，腿部缩短
    • 仰视时下半身拉长，头部缩小

十一、内容总结

  • 核心要点：
    • 透视变形需同时处理比例变化和叠压关系
    • 火柴人关节处应加粗表现体积感
    • 空间锚点决定肢体摆放合理性
  • 练习建议：
    • 先掌握标准素体比例再尝试动态夸张
    • 通过轮廓勾画+结构分析强化透视理解
    • 使用方块模板辅助透视练习

十二、知识小结

核心知识点总结
