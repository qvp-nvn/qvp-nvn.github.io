Windows 10 磁盘分区

发表于2024-01-04|更新于2026-10-06|工具效率

新电脑只有一个 C 盘，或者想把游戏、素材单独放一个盘 —— 这篇把 Windows 10 下分区的三种方法（系统工具 / 命令行 / 第三方）和常见翻车点整理清楚。

一、先想清楚要不要分

分盘的好处 分盘的代价
系统盘满了不会拖累整个电脑 每个盘空间固定，后期调整麻烦
重装系统只格式化 C 盘，资料盘不受影响 盘之间移动文件较慢（跨分区）
文件分类清晰，备份方便 分配不均时容易某个盘爆满

现在的建议：SSD 上分 2 个区就够（系统盘 + 数据盘）。机械硬盘可以按需多分。不用刻意追求「四个盘」，反而容易顾此失彼。

二、动手前必做

分区涉及磁盘底层结构，任何一步出错都可能导致数据丢失。开始前：

  1. 重要文件备份到移动硬盘或云盘（这是唯一真正保险的做法）
  2. 笔记本保证接电源，中途断电风险极高
  3. 确认 BitLocker 已关闭（控制面板 → BitLocker 驱动器加密）

三、方法一：Windows 自带「磁盘管理」（推荐新手）

打开磁盘管理

任选一种：

  • 右键「此电脑」→ 管理 → 左侧「存储」→ 磁盘管理
  • Win + X → 磁盘管理
  • Win + R → 输入 diskmgmt.msc → 回车

打开后能看到所有磁盘和分区的图形条：蓝色是主分区，黑色是未分配空间。

第一步：压缩卷（腾出空间）

  1. 选择要拆分的那个盘（通常是 C 盘），右键 → 压缩卷
  2. 系统会自动计算可压缩空间，稍等几秒
  3. 在弹出的窗口输入要压缩出的容量

单位换算：这里填的是 MB。想要 100GB 就填 100 × 1024 = 102400。

另外，「可用压缩空间大小」通常远小于磁盘剩余空间，这是正常的 —— 见第六节的原因与解法。

  1. 点击「压缩」，完成后会出现一块黑色的「未分配」区域

第二步：新建简单卷（建立新盘）

  1. 右键那块未分配的黑色区域 → 新建简单卷
  2. 进入向导，一路「下一步」：
    • 指定卷大小 —— 用满就保持默认；想再分几个区就填小一点
    • 分配驱动器号 —— 选一个没用过的字母（如 D、E）
    • 格式化分区 —— 文件系统选 NTFS，勾选「执行快速格式化」，卷标可以填「数据」「游戏」之类
  3. 点击「完成」

稍等几秒，打开「此电脑」就能看到新分区了。

第三步：删除分区（收回到未分配）

需要合并分区时用：右键分区 → 删除卷 → 确认。删除后该区域变回黑色未分配，可再分配给相邻分区。

四、方法二：diskpart 命令行

图形界面搞不定时用它（比如压缩卷按钮灰显、需要精确控制）。

list disk 后务必核对磁盘容量再 select，选错磁盘会操作到移动硬盘甚至另一块系统盘。clean 命令会清空整块磁盘，不到万不得已不要用。

五、方法三：第三方工具

自带工具搞不定的场景（调整分区大小、合并相邻分区、MBR 转 GPT），用第三方更省事：

工具 特点
傲梅分区助手 免费、中文、操作直观，支持无损调整大小
DiskGenius 功能强大，数据恢复也强，免费版够用
MiniTool Partition Wizard 界面友好，免费版有功能限制

傲梅分区助手的「分配空闲空间」功能可以直接把 D 盘的空余空间划给 C 盘，这是系统自带工具做不到的（自带工具要求空间必须相邻且在右侧）。

六、分区表与文件系统

MBR 还是 GPT

MBR GPT
最大磁盘 2 TB 理论无上限
主分区数量 最多 4 个 最多 128 个
启动方式 Legacy BIOS UEFI（现在的标配）
容错 无备份分区表 有多份备份

新电脑（UEFI 启动）一律是 GPT。查看方式：磁盘管理里右键磁盘（左侧「磁盘 0」那块）→ 属性 → 卷 → 分区样式。老机器想用 2TB 以上硬盘必须转 GPT。

文件系统怎么选

格式 单个文件上限 适用
NTFS 16 TB Windows 分区默认选择，支持权限、压缩、加密
exFAT 16 EB U 盘、移动硬盘，Win/Mac 通用
FAT32 4 GB 老设备、车载 U 盘（放不下高清电影）

七、常见问题

「可用压缩空间」远小于剩余空间

原因：NTFS 里有些不可移动的文件卡在磁盘中间，压缩只能到它们的位置为止。常见的是：

  • 页面文件 pagefile.sys（虚拟内存）
  • 休眠文件 hiberfil.sys
  • 系统还原点 / 卷影复制
  • MFT 主文件表等元数据

机械硬盘还可以先做一次碎片整理（优化驱动器），把文件挪到前面，能多腾出空间。

压缩卷 / 扩展卷按钮是灰的

原因 解法
磁盘是「动态磁盘」 需先转回基本磁盘（数据会丢，先备份）
分区是 FAT32 或未格式化 转成 NTFS：convert X: /fs:ntfs
BitLocker 已加密 先解密
剩余空间为 0 先清理磁盘

扩展卷灰显，扩不了 C 盘

Windows 自带的「扩展卷」只能吸收右侧紧邻的未分配空间。如果你的 C 盘右边是 D 盘，即使把 D 盘删了，也只有 D 盘能扩展，C 盘不行 —— 必须用第三方工具（傲梅、DiskGenius）来移动分区。

新建的分区在「此电脑」看不到

多半是没格式化或没分配盘符。回到磁盘管理，右键该分区 → 更改驱动器号和路径 → 添加一个盘符即可。

八、分区方案参考

硬盘 建议
512GB SSD C 盘 200GB（系统+软件）+ D 盘剩余（资料）
1TB SSD C 盘 250～300GB，剩余做数据盘
1TB SSD + 2TB HDD SSD 装系统和常用软件，HDD 存影音素材与备份

C 盘别分太小。Windows 本身约 30GB，加上更新、软件默认安装路径、缓存目录，200GB 是较稳妥的下限，低于 150GB 未来大概率要扩容。

九、最后确认

分区完成后检查这几项：

  • 「此电脑」里新盘符可见且能正常读写
  • 磁盘管理中无异常状态（不显示「未分配」残留）
  • 原分区的文件完好无损
  • 固态硬盘的 4K 已对齐（见上文命令）
  • 若之前关了休眠/系统保护，按需重新开启

最省心的顺序：备份 → 磁盘管理压缩卷 → 新建简单卷。自带工具足够应付 90% 的需求，需要跨分区挪空间时再上第三方工具。
